# Receipt Wrangler — Sales Kit (v5.1)

## One-liner
Receipt Wrangler is a private, offline Android app for capturing receipts, fixing OCR misses, cleaning duplicates, and exporting submission-ready packets.

## Who it is for
- business reimbursement users
- freelancers and contractors
- tax-season organizers
- personal finance cleanup users
- gig vendors reconciling sales vs costs

## Core promise
- no account
- no cloud sync
- no analytics
- no internet dependency for core workflows
- all receipt work stays on-device unless user explicitly exports

## Why it wins
1. Capture + import flexibility
   - camera capture
   - image/PDF import
   - Android share/open-with import support

2. Practical OCR reliability
   - on-device OCR for images/PDFs
   - confidence cues and review queue
   - emergency fallback for rough handwritten/low-legibility captures

3. Real cleanup and control
   - crop/rotate/grayscale/contrast cleanup
   - duplicate scoring and merge with traceability notes
   - batch status/category actions
   - configurable theme mode (system/light/dark)

4. Exports teams actually need
   - CSV
   - JSON backup/restore
   - markdown report packet
   - PDF packet with receipt evidence images (from image and PDF sources)
   - gig sales PDF

5. Lane-based workflow
   - business, tax, personal, freelancer, gig-profit + additional persona lanes
   - lane-aware coaching and report naming defaults

## Demo script (5 minutes)
1. Import 2 receipts (image + PDF).
2. Show OCR confidence and low-confidence cue.
3. Run scan cleanup on one difficult receipt.
4. Merge duplicate pair and show trace note.
5. Switch to gig lane and show auto sales-vs-expense math.
6. Export PDF packet and sales PDF.
