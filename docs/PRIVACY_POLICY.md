# Privacy Policy

Receipt Wrangler is designed to minimize data liability.

## What the app does not do
- no account creation
- no remote analytics
- no ad SDKs
- no cloud sync
- no background upload of receipt data
- no internet dependency for core capture/review/export workflows
- no receipt content sent to remote OCR or AI services

## What stays on-device
- receipt images copied into app-private storage
- rendered receipt evidence used only for local PDF export generation
- OCR text
- metadata such as merchant, total, date, category, and notes
- local backup files only when the user explicitly exports them

Camera permission is requested only for in-app capture.
Document access is used only when the user imports or exports via Android's picker.

## What leaves the device
Nothing by default.

The only time data leaves app-private storage is when the user explicitly exports:
- CSV
- backup JSON
- markdown report packets
- PDF packets
- gig sales PDF

Those files are written only to user-chosen locations via Android's document picker.

## Data retention
Receipts are retained indefinitely in app-private storage until the user deletes them.
Backup files are retained only as long as the user keeps the exported files.
No automatic cleanup or expiration.
